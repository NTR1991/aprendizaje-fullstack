# 📘 PHP Introduction

## 📋 Description

A PHP script to verify the PHP environment setup, displaying system configuration, a personalized welcome message with the current date, and the PHP version.

---

## 🎯 Learning Objectives

- Understanding `phpinfo()` and its output.
- Using variables and string concatenation in PHP.
- Displaying formatted dates with `date()`.
- Retrieving the PHP version with `PHP_VERSION`.

---

## 📝 Exercises (Real-World Scenarios)

### 🟢 Normal Level (5 exercises)

1. **PHP Environment Configuration**
   As a junior developer joining a new team, your first task is to verify your local PHP environment. Create a PHP script that displays:
   - The complete PHP configuration using `phpinfo()`.
   - A personalized welcome message with your full name and current date.
   - The PHP version you are using.
