# 📘 PHP Syntax

## 📋 Description

A PHP script demonstrating the correct use of PHP syntax, including tags, instructions, comments, variables, arithmetic operations, and formatted output in a real-world client management scenario.

---

## 🎯 Learning Objectives

- Understanding PHP opening and closing tags (`<?php ... ?>`)
- Using single-line comments (`//`) and multi-line comments (`/* ... */`)
- Declaring variables with descriptive and unique names
- Using `echo` to display formatted output with concatenation
- Performing basic arithmetic operations (`*`, `/`, `+`)
- Using `date()` to display the current date in different formats
- Understanding the importance of semicolons (`;`) at the end of instructions
- Using `\n` for line breaks in console output

---

## 📝 Exercises (Real-World Scenarios)

### 🟢 Normal Level (1 exercise)

1. **Client Management System Setup**
   As a junior developer at a marketing agency, you need to validate the basic PHP syntax for the client management system. Create a PHP script that demonstrates:
   - Correct use of PHP tags and instructions.
   - Single-line and multi-line comments documenting the code.
   - Variables with descriptive names (`$clienteNombre1`, `$clienteFecha1`, `$clienteEmpresa1`, `$clienteProyecto1`).
   - A welcome message displayed with `echo` and concatenation.

---

### 🟡 Intermediate Level (1 exercise)

1. **Client Billing Summary**
   The marketing agency needs a billing summary for their management system. Create a PHP script that calculates and displays:
   - Client name, company, registration date.
   - Years active and annual billing.
   - Total billing (annual billing × years active).
   - VAT (21% of total billing).
   - Final total (total billing + VAT).
   - All variables must have unique names (`$clienteNombre2`, `$clienteEmpresa2`, etc.).

---

### 🔴 Difficult Level (1 exercise)

1. **Complete Client Profile**
   The agency needs a complete client profile for their administration platform. Create a PHP script that displays:
   - Personal data (name, company, contact person, email).
   - Financial data (annual billing, seniority).
   - Calculated billing totals (total billing, VAT, final total).
   - All variables must have unique names (`$perfilNombre3`, `$perfilEmpresa3`, etc.).
   - Professional formatting with clear section separators.
