# 📘 Bloque 1: Fundamentos de PHP

## 📋 Description

This block covers the fundamental concepts of PHP programming, from basic syntax and variables to control structures like conditionals and loops. Each topic is practiced with real-world business scenarios to ensure practical understanding.

---

## 📚 Topics Covered

| # | Topic | Description |
|---|-------|-------------|
| 01 | Introduction | PHP environment setup, phpinfo(), basic structure |
| 02 | Syntax | PHP tags, comments, instructions, semicolons |
| 03 | Variables | Variable declaration, naming conventions, data types |
| 04 | Echo / Print | Displaying output, differences between echo and print |
| 05 | Data Types | Strings, integers, floats, booleans, arrays, null |
| 06 | Strings | String manipulation: trim(), strlen(), substr(), str_replace(), explode(), implode() |
| 07 | Numbers | Integers, floats, mathematical operations, round(), ceil(), floor(), number_format() |
| 08 | Casting | Type conversion: (int), (float), (bool), (string) |
| 09 | Math | Mathematical functions: pi(), min(), max(), abs(), sqrt(), pow(), rand() |
| 10 | Constants | define(), const, defined(), naming conventions |
| 11 | Magic Constants | __LINE__, __FILE__, __DIR__, __FUNCTION__, __CLASS__, __METHOD__, __NAMESPACE__ |
| 12 | Operators | Arithmetic, assignment, comparison, logical, increment/decrement, string, ternary, null coalescing |
| 13 | If...Else...Elseif | Conditional statements, if, else, elseif, nested if, logical operators |
| 14 | Switch | Switch statement, case, break, default, comparing with if...elseif |

---

## 🎯 Learning Objectives

By the end of this block, you should be able to:

- Write basic PHP scripts with proper syntax and structure
- Declare and use variables of different data types
- Use echo and print to display output
- Manipulate strings and numbers effectively
- Perform type conversions using casting
- Use mathematical functions for calculations
- Define and use constants and magic constants
- Use operators for arithmetic, comparison, logic, and assignment
- Implement conditional logic using if...else...elseif and switch
- Apply all concepts in real-world business scenarios
