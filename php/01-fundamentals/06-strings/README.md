# 📘 PHP Data Types

## 📋 Description

A PHP script demonstrating the different data types available in PHP, including `string`, `int`, `float`, `bool`, `array`, and `null`. The script shows how to declare variables of each type, display their values, and identify their types using `gettype()` and `var_dump()` in real-world business scenarios.

---

## 🎯 Learning Objectives

- Understanding PHP data types: `string`, `int`, `float`, `bool`, `array`, `null`
- Declaring variables with different data types
- Using `gettype()` to identify the data type of a variable
- Using `var_dump()` to display detailed information about a variable
- Using `implode()` to convert an array into a readable string
- Displaying boolean values as human-readable text
- Differentiating between single quotes (`'`) and double quotes (`"`)

## 📝 Exercises (Real-World Scenarios)

### 🟢 Normal Level (1 exercise)

1. **Employee Data Registration**
   A company needs to register and display employee data with their corresponding data types. The script must include:
   - Full name (string)
   - Age (int)
   - Height in meters (float)
   - Active status (bool)
   - Skills (array)
   
   Create a PHP script that:
   - Declares variables for each employee data point.
   - Uses `gettype()` to display the data type of each variable.
   - Uses `implode()` to display the skills array as a readable string.
   - Uses `echo` to display the data with professional formatting.
