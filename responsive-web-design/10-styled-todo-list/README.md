# ✅ Styled To-Do List

## 📋 Description

A styled to-do list with checkboxes, labels, and nested sub-items with links. Designed to practice CSS pseudo-classes and interactive styling.

---

## 🎯 Learning Objectives

- Using CSS pseudo-classes (`:link`, `:hover`, `:active`, `:visited`, `:focus`)
- Structuring forms with `<input>` and `<label>`
- Creating nested lists (`<ul>` inside `<li>`)
- Applying `text-decoration: none` for clean links

---

## 📝 Code Content

### Features

| Element | Description |
| :--- | :--- |
| Checkbox | Marks tasks as completed |
| Label | Descriptive text for each task |
| Sub-item | Nested list with related links |
| Links | Open in a new tab (`target="_blank"`) |

### Link Styles

| State | Color |
| :--- | :--- |
| `:link` (unvisited) | Blue (`#0000ff`) |
| `:visited` | Purple |
| `:hover` | Red |
| `:active` | Green |
| `:focus` | Orange border |

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure with forms and lists
- **CSS3** – Pseudo-classes (`:link`, `:hover`, `:active`, `:visited`, `:focus`)
