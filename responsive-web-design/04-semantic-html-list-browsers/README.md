# 🌐 Semantic HTML: List of Browsers

## 📋 Description

An exercise from the **Responsive Web Design** course on freeCodeCamp. This project demonstrates the use of semantic HTML description lists (`<dl>`) to display information about major web browsers.

---

## 🎯 Learning Objectives

- Using description lists (`<dl>`, `<dt>`, `<dd>`)
- Structuring information semantically
- Creating a clean, well-formatted HTML page

---

## 📝 Code Content

| HTML Element | Content |
| :--- | :--- |
| `<h1>` | "List of Major Web Browsers" |
| `<dl>` | Description list of browsers (Google Chrome, Firefox, Safari, Brave, Arc) |
| `<dt>` | Browser names (terms) |
| `<dd>` | Browser descriptions |

---

## 🛠️ Technologies Used

- **HTML5** – Semantic description lists
