# BucleDoWhile 🔄

## 📋 Description

Escribe un programa que muestre los números del 1 al 5 usando un bucle `do-while`.

**Expected output:**
```
1
2
3
4
5
```

## 🧮 Code

```java
public class BucleDoWhile {
    public static void main(String[] args) {
        int i = 1;
        do {
            System.out.println(i);
            i++;
        } while (i <= 5);
    }
}
```
