# Entre10y20 🔢

## 📋 Description

Returns true if the number is between 10 and 20 inclusive.

---

## 🛠️ Technologies Used

- ☕ Java

---

## 📁 Project Structure

Entre10y20.java  
README.md

---

## 🧮 Code

````public class Entre10y20 {
    public static boolean entre10y20(int n) {
        return n >= 10 && n <= 20;
    }
}
````

---

## 📊 Examples

| n | Result |
|---|--------|
| 10 | true |
| 15 | true |
| 20 | true |
| 9 | false |
| 21 | false |
