# EsPositivoYPar 🔢

## 📋 Description

Returns true if the number is positive AND even.

## 🧮 Code

````public class EsPositivoYPar {
    public static boolean esPositivoYPar(int numero) {
        return numero > 0 && numero % 2 == 0;
    }
}
````
