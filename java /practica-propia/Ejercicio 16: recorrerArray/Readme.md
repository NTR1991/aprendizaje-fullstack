# RecorrerArray 🔄

## 📋 Description

Con el mismo array `{10, 20, 30, 40, 50}`, recórrelo con un bucle `for` y muestra cada elemento en una línea.

**Expected output:**
```
10
20
30
40
50
```

## 🧮 Code

```java
public class RecorrerArray {
    public static void main(String[] args) {
        int[] numeros = {10, 20, 30, 40, 50};
        for (int i = 0; i < numeros.length; i++) {
            System.out.println(numeros[i]);
        }
    }
}
```
