# RangoEspecial 🎯

## 📋 Description

Returns true if the number is between 0 and 10 inclusive, OR exactly 20.

## 🧮 Code

public class RangoEspecial {
    public static boolean rangoEspecial(int n) {
        return (n >= 0 && n <= 10) || n == 20;
    }
}
