# FueraDeRango5a15 🚫

## 📋 Description

Returns true if the number is less than 5 OR greater than 15.

## 🛠️ Technologies Used

- ☕ Java

## 🧮 Code

````public class FueraDeRango5a15 {
    public static boolean fueraDeRango5a15(int n) {
        return n < 5 || n > 15;
    }
}
````

| n | Result |
|---|--------|
