# SumDouble

## 📋 Description

Return the sum of two integers. If they are the same, return double their sum.

**Problem:** CodingBat - sumDouble

## 🛠️ Technologies Used

- Java

## 📁 Project Structure

03-sumDouble/
├── SumDouble.java
└── README.md

## 🧮 Code

```java
public class SumDouble {
    public static int sumDouble(int a, int b) {
        if (a == b) {
            return (a + b) * 2;
        }
        return a + b;
    }
}
````

| a | b | Result |
|---|---|--------|
| 1 | 2 | 3 |
| 3 | 3 | 12 |
