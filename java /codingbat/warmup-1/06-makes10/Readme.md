# Makes10 🔟

## 📋 Description

Return true if one of the numbers is 10 or if their sum is 10.

**Problem:** CodingBat - makes10

## 🧮 Code

```java
public class Makes10 {
    public static boolean makes10(int a, int b) {
        return a == 10 || b == 10 || a + b == 10;
    }
}
````

## 📊 Examples

| a | b | Result |
|---|---|--------|
| 9 | 10 | true |
| 9 | 9 | false |
| 1 | 9 | true |
