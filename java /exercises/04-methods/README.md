# 📐 Methods in Java

## 📋 Description

This folder contains Java exercises focused on **method creation**, **parameter handling**, and **return values**. Each exercise practices a specific technique for writing reusable methods.

---

## 📂 Folder Structure

```
java/
└── methods/
    ├── 12_MaxTres.java
    ├── 13_MinTres.java
    └── 14_MedioTres.java
```

---

## 📊 Exercises Overview

| Exercise | Name | Description |
| :--- | :--- | :--- |
| 12 | `MaxTres` | Returns the maximum of three integers using conditional logic. |
| 13 | `MinTres` | Returns the minimum of three integers using conditional logic. |
| 14 | `MedioTres` | Returns the middle number (neither max nor min) using arithmetic or conditional logic. |

---

## 🎯 Learning Objectives

- Writing methods with parameters
- Returning values from methods
- Using conditional logic to compare values
- Finding max and min values
- Finding the middle value using arithmetic
- Understanding method signatures (`public static int methodName(int a, int b, int c)`)
- Using `Math.max()` and `Math.min()` as alternatives
