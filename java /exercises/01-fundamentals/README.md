# 🖥️ Block 01 – Fundamentals

## 📋 Description

This block covers the essential fundamentals of Java programming. It includes exercises on syntax, variables, operators, and basic String and Math methods. Each exercise is designed to simulate real-world scenarios, helping you build a strong foundation in Java.

---

## 📝 Exercise List

| #   | Exercise       | Description                                                                 |
|-----|----------------|-----------------------------------------------------------------------------|
| 30  | SyntaxMain     | Basic structure of a Java program with the `main` method.                   |
| 31  | VariablesTypes | Declaring and printing variables of different types: `int`, `double`, `String`, `boolean`. |
| 32  | Operators      | Using arithmetic operators: `+`, `-`, `*`, `/`, `%`.                        |
| 33  | StringsMath    | Using `String` methods (`length()`, `toUpperCase()`, `toLowerCase()`) and `Math` methods (`max()`, `min()`, `sqrt()`). |

---

## 🎯 Learning Objectives

By the end of this block, you should be able to:

- Write the `main` method correctly.
- Declare and use variables of different types.
- Use arithmetic operators.
- Use common `String` methods.
- Use basic `Math` methods.
