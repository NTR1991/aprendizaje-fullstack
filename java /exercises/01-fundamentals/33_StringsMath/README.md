# 📘 StringsMath

## 📋 Description

A simple Java program that demonstrates common `String` methods (`length()`, `toUpperCase()`, `toLowerCase()`) and basic `Math` methods (`max()`, `min()`, `sqrt()`).

---

## 📝 Exercise Statement

Write a program that:

1. Declares a variable `String saludo = "hola mundo"`.
2. Prints:
   - The length of the text (`saludo.length()`)
   - The text in uppercase (`saludo.toUpperCase()`)
   - The text in lowercase (`saludo.toLowerCase()`)
3. Uses the `Math` class to print:
   - `Math.max(15, 20)`
   - `Math.min(15, 20)`
   - `Math.sqrt(25)`

---

## 📊 Expected Output

| Operation | Result |
|-----------|--------|
| Longitud  | 10     |
| Mayúsculas | HOLA MUNDO |
| Minúsculas | hola mundo |
| Máximo    | 20     |
| Mínimo    | 15     |
| Raíz cuadrada de 25 | 5.0 |

---

## 🎯 Learning Objectives

- Using `String` methods: `length()`, `toUpperCase()`, `toLowerCase()`
- Using `Math` methods: `max()`, `min()`, `sqrt()`
- Combining string and mathematical operations in a single program
