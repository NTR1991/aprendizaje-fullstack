# 🖨️ SyntaxMain

## 📋 Description

A simple Java program that prints a name and an age to the console. This exercise demonstrates the basic structure of a Java program, including the `main` method and `System.out.println()`.

---

## 📝 Code

```java
public class SyntaxMain {
    public static void main(String[] args) {
        System.out.println("Ana Garco");
        System.out.println("25");
    }
}
```

---

## 📊 Output

```
Ana Garco
25
```

---

## 🎯 Learning Objectives

- Understanding the `main` method signature: `public static void main(String[] args)`
- Using `System.out.println()` to print to the console
- Running a Java program

---

## 🛠️ Technologies Used

- **Java** – Core language, `main` method, console output
