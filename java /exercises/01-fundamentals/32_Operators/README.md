# 📘 Operators

## 📋 Description

A simple Java program that demonstrates the use of arithmetic operators: addition, subtraction, multiplication, division, and modulus.

---

## 📝 Exercise Statement

Write a program that declares two integer variables `a = 10` and `b = 3`. Perform the following operations and display each result with a descriptive label:

1. Addition (`a + b`)
2. Subtraction (`a - b`)
3. Multiplication (`a * b`)
4. Division (`a / b`)
5. Modulus / Remainder (`a % b`)

---

## 📊 Expected Output

| Operation | Result |
|-----------|--------|
| Suma      | 13     |
| Resta     | 7      |
| Multiplicacion | 30 |
| Division  | 3      |
| Resto     | 1      |

---

## 🎯 Learning Objectives

- Declaring integer variables
- Using arithmetic operators: `+`, `-`, `*`, `/`, `%`
- Printing results with descriptive messages

## 🛠️ Technologies Used

- Java – Core language, arithmetic operators, console output
