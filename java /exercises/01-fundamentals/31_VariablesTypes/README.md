# 📘 VariablesTypes

## 📋 Description

A simple Java program that declares variables of different types (`int`, `double`, `String`, `boolean`) and prints them to the console. This exercise demonstrates how to store and display different kinds of data in Java.

---

## 📝 Code

```java
public class VariablesTypes {
    public static void main(String[] args) {
        int edad = 25;
        double altura = 1.75;
        String nombre = "Ana";
        boolean esEstudiante = true;

        System.out.println("Edad: " + edad);
        System.out.println("Altura: " + altura);
        System.out.println("Nombre: " + nombre);
        System.out.println("Es estudiante: " + esEstudiante);
    }
}
```

---

## 📊 Output

```
Edad: 25
Altura: 1.75
Nombre: Ana
Es estudiante: true
```
