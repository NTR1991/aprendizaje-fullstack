# ⚙️ Control Flow in Java

## 📋 Description

This folder contains Java exercises focused on **control flow structures**: `while`, `do-while`, `switch`, and a simple calculator. Each exercise demonstrates a different way to control the flow of execution in a Java program.

---

## 📂 Folder Structure

```
java/
└── control-flow/
    ├── 26_BucleWhile.java
    ├── 27_BucleDoWhile.java
    ├── 28_SwitchDias.java
    └── 29_CalculadoraSimple.java
```

---

## 📊 Exercises Overview

| Exercise | Name | Description |
| :--- | :--- | :--- |
| 26 | `BucleWhile` | Displays numbers from 1 to 5 using a `while` loop. |
| 27 | `BucleDoWhile` | Displays numbers from 1 to 5 using a `do-while` loop. |
| 28 | `SwitchDias` | Displays the day name based on a numeric input using `switch`. |
| 29 | `CalculadoraSimple` | A simple calculator that performs basic operations (`+`, `-`, `*`, `/`) using `switch`. Handles division by zero. |

---

## 🎯 Learning Objectives

- Using `while` loops for iteration
- Using `do-while` loops for at-least-once execution
- Using `switch` statements for multiple condition checks
- Handling edge cases (division by zero, invalid input)
- Combining input handling with control flow
- Writing methods with return values
