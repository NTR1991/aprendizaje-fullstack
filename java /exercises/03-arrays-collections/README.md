# 📊 Arrays and Collections in Java

## 📋 Description

This folder contains Java exercises focused on **arrays** and **collections** (ArrayList). Each exercise practices a specific operation or technique for working with groups of data.

## 📊 Exercises Overview

| Exercise | Name | Description |
| :--- | :--- | :--- |
| 15 | `CrearArray` | Creates an array and prints the first and last elements. |
| 16 | `RecorrerArray` | Iterates through an array using a `for` loop. |
| 17 | `SumarArray` | Calculates the sum of all elements in an array. |
| 18 | `MaximoArray` | Finds the maximum value in an array. |
| 19 | `MinimoArray` | Finds the minimum value in an array. |
| 20 | `ContarParesArray` | Counts how many even numbers are in an array. |
| 21 | `BuscarElementoArray` | Searches for a specific value in an array. |
| 22 | `ArrayListBasico` | Creates an ArrayList, adds elements, and iterates with for-each. |
| 23 | `ArrayListConEnteros` | Creates an ArrayList, removes an element by index, and displays the result. |

---

## 🎯 Learning Objectives

- Creating and initializing arrays
- Iterating through arrays with `for` loops
- Finding maximum and minimum values in an array
- Accumulating values with `sum`
- Using methods like `push`, `splice`, `indexOf`, `filter`, `map`, `reduce`
- Working with `ArrayList` (add, remove, size, get)
- Using for-each loops with collections
- Understanding the difference between arrays and `ArrayList`
- Using the `length` property for arrays and `size()` for `ArrayList`
