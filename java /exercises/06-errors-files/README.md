# 🚨 Block 06 – Errors and Files

## 📋 Description

This block covers error handling in Java using `try-catch` blocks, multiple exceptions, and manual validation with `if`. These techniques are essential for building robust programs that do not crash when unexpected inputs or situations occur.

---

## 📝 Exercise List

| #   | Exercise           | Description                                                                 |
|-----|--------------------|-----------------------------------------------------------------------------|
| 43  | TryCatch           | Convert euros to dollars, handle `NumberFormatException`.                   |
| 43  | DivisionSegura     | Divide two numbers, handle text and division by zero manually.             |
| 44  | MultipleExceptions | Divide two integers, handle `NumberFormatException` and `ArithmeticException`. |

---

## 🎯 Learning Objectives

By the end of this block, you should be able to:

- Use `try-catch` to handle `NumberFormatException`.
- Use multiple `catch` blocks for different exceptions.
- Understand the difference between `if` validation and `try-catch`.
- Know that `ArithmeticException` only applies to integers.
- Use `Double.parseDouble()` and `Integer.parseInt()` safely.
