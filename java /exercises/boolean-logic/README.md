# 🧠 Boolean Logic in Java

## 📋 Description

This folder contains Java exercises focused on **boolean logic**, **conditional statements**, and **logical operators**. Each exercise is a small, self-contained program that practices a specific logical scenario.

## 📊 Exercises Overview

| Exercise | Name | Description |
| :--- | :--- | :--- |
| 01 | `PuedeVotar` | Checks if a person is 18 or older AND is a citizen. |
| 02 | `TieneDescuento` | Returns true if purchase amount > 100 OR user is an employee. |
| 03 | `PuedeSubirMontanaRusa` | Checks height and companion to determine ride eligibility. |
| 04 | `EsNumeroEspecial` | Returns true if number is between 5 and 10 inclusive, except 7. |
| 05 | `PuedeConducir` | Returns true for practice driving (age >= 16), age >= 65, or age >= 18 with license. |
| 06 | `DiaDePlaya` | Returns true if it's sunny AND there is no strong wind. |
| 07 | `EsPositivoYPar` | Returns true if the number is positive AND even. |
| 08 | `DescuentoPorVolumen` | Returns true if quantity >= 10 OR is a frequent customer (except qty 0). |
| 09 | `Entre10y20` | Returns true if the number is between 10 and 20 inclusive. |
| 10 | `FueraDeRango5a15` | Returns true if the number is less than 5 OR greater than 15. |
| 11 | `RangoEspecial` | Returns true if the number is between 0 and 10 inclusive, OR exactly 20. |

---

## 🎯 Learning Objectives

- Practicing boolean logic with `&&`, `||`, and `!` operators
- Using `if/else` and `switch` statements
- Combining multiple conditions
- Understanding operator precedence
- Handling edge cases (0, negatives, boundaries)
- Writing methods that return boolean values
