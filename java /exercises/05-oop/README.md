# 🐕 Object-Oriented Programming in Java

## 📋 Description

This folder contains Java exercises focused on **Object-Oriented Programming (OOP)** concepts. Each exercise practices creating classes, attributes, constructors, and methods.

---

## 📂 Folder Structure

```
java/
└── oop/
    ├── 24_ClasePerro.java
    └── 25_ClaseGato.java
```

---

## 📊 Exercises Overview

| Exercise | Name | Description |
| :--- | :--- | :--- |
| 24 | `ClasePerro` | Creates a `Perro` class with private attributes (`nombre`, `edad`), a constructor, and a `ladrar()` method. |
| 25 | `ClaseGato` | Creates a `Gato` class with private attributes (`nombre`, `color`), a constructor, and a `maullar()` method. |

---

## 🎯 Learning Objectives

- Creating classes with private attributes (encapsulation)
- Implementing constructors with parameters
- Using the `this` keyword
- Creating methods with return types (`void`)
- Accessing instance variables
- Basic OOP structure in Java
