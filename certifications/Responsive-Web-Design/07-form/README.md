# 📝 Hotel Feedback Form

## 📋 Description

A feedback form for a hotel stay, built as part of the **Responsive Web Design** course on freeCodeCamp. It includes various input types, radio buttons, checkboxes, and a dropdown menu.

---

## 🎯 Learning Objectives

- Structuring forms with semantic HTML
- Using different input types: `text`, `email`, `number`, `radio`, `checkbox`
- Using `<select>` and `<textarea>` for multiple options and comments
- Applying native validation with `required`, `min`, `max`
- Using `checked` and `selected` attributes for default values

---

## 📝 Code Content

| Section | Fields |
| :--- | :--- |
| **Personal Information** | Name (text), Email (email), Age (number) |
| **Guest Experience** | First time at hotel (radio) |
| **Reasons for choosing** | Multiple options (checkbox) |
| **Ratings** | Service (select), Food (select) |
| **Additional comments** | Textarea for free comments |

---

### Key Features

| Feature | Description |
| :--- | :--- |
| `required` | Mandatory fields (Name, Email) |
| `min="3" max="100"` | Valid age range |
| `checked` | Pre-selected checkbox option |
| `selected` | Default option in selects |
| `type="email"` | Email format validation |
| `method="POST"` | Data submission to freeCodeCamp API |

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure (`<header>`, `<main>`, `<fieldset>`, `<legend>`)
- **HTML Forms** – Native validation and input types
- **POST Method** – Submission to `https://hotel-feedback.freecodecamp.org`
