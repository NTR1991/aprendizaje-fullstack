# 👤 Camperbot About

## 📋 Description

A simple "About" page for Camperbot, created as part of the **Responsive Web Design** course on freeCodeCamp. It introduces a character and their interests using semantic HTML.

---

## 🎯 Learning Objectives

- Creating a simple personal profile page
- Using heading tags (`<h1>`, `<h2>`, `<h3>`)
- Writing descriptive paragraphs

---

## 📝 Code Content

| HTML Element | Content |
| :--- | :--- |
| `<h1>` | "Hello from Camperbot!" |
| `<h2>` | "About" |
| `<h3>` | "Background and Interests" |
| `<p>` | Introduction and hobbies |

---

## 🛠️ Technologies Used

- **HTML5** – Semantic heading and paragraph tags
