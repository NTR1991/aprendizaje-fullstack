# 👤 Camperbot About

Ejercicio del curso **Responsive Web Design** de freeCodeCamp.

## 🎯 Objetivo

Crear una página "Acerca de" (About) para Camperbot, presentando información personal y antecedentes.

## 📝 Contenido del código

- `<h1>` Título: "Hello from Camperbot!"
- `<h2>` Subtítulo: "About"
- `<h3>` Subsección: "Background and Interests"
- `<p>` Descripciones: Presentación y aficiones (resolver puzzles)

## 🛠️ Tecnologías

- HTML5 (etiquetas de título y párrafo)

## 📂 Archivo

- `index.html` - Página Acerca de Camperbot
