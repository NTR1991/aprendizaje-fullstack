# 💼 Quincy's Tips for Getting a Developer Job

Ejercicio del curso **Responsive Web Design** de freeCodeCamp.

## 🎯 Objetivo

Crear una página con consejos de Quincy Larson (fundador de freeCodeCamp) sobre cómo conseguir trabajo como desarrollador, aplicando citas y referencias.

## 📝 Contenido del código

- `<h1>` Título: "Quincy's Tips for Getting a Developer Job"
- `<main>` Contenedor principal
- `<section>` Tres secciones: Envisioning Success, Importance of Networking, Importance of Building a Reputation
- `<blockquote>` Citas largas de Quincy Larson
- `<q>` Cita corta en el párrafo inicial
- `<cite>` Referencia al libro/fuente
- `<p>` Párrafos con consejos adicionales

## 🛠️ Tecnologías

- HTML5 semántico (`<main>`, `<section>`, `<blockquote>`, `<q>`, `<cite>`)

## 📂 Archivo

- `index.html` - Consejos para conseguir trabajo de desarrollador
