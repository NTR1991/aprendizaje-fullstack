# 🃏 Blog Post Card

## 📋 Description

A blog post card component displaying an image, title, excerpt, and a "Read More" link. Designed with a centered layout, hover effects, and modern styling.

---

## 🎯 Learning Objectives

- Structuring a card component with semantic HTML
- Using CSS Flexbox for centering and alignment
- Applying `border-radius`, `box-shadow`, and `:hover` for interactivity
- Creating responsive images with `width: 100%`

---

## 📝 Code Content

### Elements

| Element | Description |
| :--- | :--- |
| Card container | White background, rounded corners, shadow |
| Image | Full width, bottom border |
| Title | Dark gray (`#333`), custom margins |
| Excerpt | Gray (`#666`), bottom margin |
| "Read More" button | Blue background, white text, rounded corners |

### Hover Effects

| Element | Effect |
| :--- | :--- |
| Card | Slight lift (via `transform` or `box-shadow`) |
| Button | Background and text color change, pointer cursor |

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Flexbox, `border-radius`, `box-shadow`, `:hover`, `display: inline-block`
