# Blog Post Card

## 📋 Descripción

Tarjeta de publicación de blog (blog post card) que muestra una imagen, título, extracto y un enlace "Read More". Diseño centrado con efectos hover y estilos modernos.

## 🛠️ Tecnologías utilizadas

- **HTML5 semántico**
- **CSS3** (Flexbox, hover, border-radius, box-shadow)

## 📁 Estructura del proyecto

11-blog-post-card/
├── index.html
├── styles.css
└── README.md


## 🎨 Estilos implementados

| Elemento | Estilo |
|----------|--------|
| Tarjeta | Fondo blanco, bordes redondeados, sombra |
| Imagen | Ancho completo, borde inferior |
| Título | Color #333, márgenes personalizados |
| Extracto | Color #666, margen inferior |
| Botón Read More | Fondo azul, texto blanco, bordes redondeados |
| Hover | Cambio de color y fondo, cursor pointer |

## 📚 Aprendizajes aplicados

- ✅ `border-radius` para bordes redondeados
- ✅ `box-shadow` para efecto de elevación
- ✅ `:hover` para interacción
- ✅ `width: 100%` para imágenes responsivas
- ✅ `display: inline-block` para botones
- ✅ `margin: 0 auto` para centrar
