# Styled To-Do List

## 📋 Descripción

Lista de tareas (to-do list) con estilo, que incluye casillas de verificación, etiquetas y sub-elementos con enlaces. Diseño interactivo con pseudo-clases CSS.

## 🛠️ Tecnologías utilizadas

- **HTML5 semántico**
- **CSS3** (pseudo-clases: `:link`, `:hover`, `:active`, `:visited`, `:focus`)

## 📁 Estructura del proyecto

10-styled-todo-list/
├── index.html
├── styles.css
└── README.md

## ✅ Características

| Elemento | Descripción |
|----------|-------------|
| Checkbox | Casillas para marcar tareas completadas |
| Label | Texto descriptivo de cada tarea |
| Sub-item | Lista anidada con enlaces relacionados |
| Enlaces | Abren en nueva pestaña (`target="_blank"`) |

## 🎨 Estilos de enlaces

| Estado | Color |
|--------|-------|
| No visitado (`:link`) | Azul (#0000ff) |
| Visitado (`:visited`) | Morado (purple) |
| Al pasar ratón (`:hover`) | Rojo (red) |
| Al hacer clic (`:active`) | Verde (green) |
| Enfocado (`:focus`) | Borde naranja |

## 📚 Aprendizajes aplicados

- ✅ Pseudo-clases para enlaces
- ✅ `text-decoration: none` para quitar subrayado
- ✅ `target="_blank"` para abrir en nueva pestaña
- ✅ Listas anidadas (`ul` dentro de `li`)
- ✅ Estructura semántica con `input`, `label`, `a`
