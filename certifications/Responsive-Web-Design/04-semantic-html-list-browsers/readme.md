# 🌐 Lista de Navegadores (HTML Semántico)

Ejercicio del curso **Responsive Web Design** de freeCodeCamp.

## 🎯 Objetivo

Crear una lista de definición (`<dl>`) con navegadores web y sus descripciones, practicando HTML semántico.

## 📝 Contenido del código

- `<h1>` Título: "List of Major Web Browsers"
- `<dl>` Lista de definición (Description List)
- `<dt>` Términos (Google Chrome, Firefox, Safari, Brave, Arc)
- `<dd>` Descripciones de cada navegador

## 🛠️ Tecnologías

- HTML5 (lista de definición `<dl>`, `<dt>`, `<dd>`)

## 📂 Archivo

- `index.html` - Lista semántica de navegadores
