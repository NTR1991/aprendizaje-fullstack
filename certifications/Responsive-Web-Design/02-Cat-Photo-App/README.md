# 🐱 Cat Photo App

## 📋 Description

A cat photo gallery application built as part of the **Responsive Web Design** course on freeCodeCamp. It includes forms, radio buttons, checkboxes, and image links.

---

## 🎯 Learning Objectives

- Building forms with `<form>` and inputs
- Using radio buttons and checkboxes
- Structuring content with `<section>` and `<figure>`
- Adding images and links

---

## 📝 Code Content

| Feature | Description |
| :--- | :--- |
| `<h1>` | "CatPhotoApp" |
| `<section>` | "Cat Photos", "Cat Lists" |
| `<ul>` | Things cats love (catnip, laser pointers, lasagna) |
| `<ol>` | Things cats hate (flea treatment, thunder, other cats) |
| `<figure>` | Images with `<figcaption>` captions |
| `<a>` | Internal and external links |
| `<img>` | Cat and food images |
| `<footer>` | Copyright notice |

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure, forms, and images
