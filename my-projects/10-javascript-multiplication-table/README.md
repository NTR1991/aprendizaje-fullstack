# Multiplication Table

## 📋 Description

JavaScript program that asks the user for a number and displays its multiplication table from 1 to 10 in the browser console.

## 🛠️ Technologies used

- **HTML5**
- **JavaScript** (prompt, for loop, console.log)

## 📁 Project structure

10-js-multiplication-table/
├── index.html
└── README.md

## 🧮 How it works

1. The program asks the user for a number using `prompt()`
2. A `for` loop runs from 1 to 10
3. The results are displayed in the **browser console** (F12 → Console)

## 📊 Example output
Enter a number: 5
5 multiplied by 1 equals 5
5 multiplied by 2 equals 10
5 multiplied by 3 equals 15
...
5 multiplied by 10 equals 50

text
