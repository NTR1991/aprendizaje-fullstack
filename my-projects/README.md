## 🧮 Functions Demonstrated

| Function | Type | Description |
|----------|------|-------------|
| `saludar1()` | No parameters, no return | Logs "Hola" to console |
| `saludar2(mensaje)` | With parameter, with return | Returns the message passed |
| `saludar3(p_nombre)` | With parameter, no return | Logs "Hola + name" to console |
| `saludar4()` | No parameters, with return | Returns a string |

## 📊 Example Output

**Console:**
