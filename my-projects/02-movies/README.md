# 🎬 Movie Catalog

Personal project: a webpage with an interactive movie table, links to details, and centered design.

---

## 🎯 Project Objective

Create a movie catalog using HTML tables, with links to individual movie pages and CSS styles for an attractive presentation.

---

## 📝 Project Content

### HTML Structure
- `<h1>` Title "Movies"
- `<table>` Movie catalog table with:
  - `<caption>` Title "Cartelera" (Movie List)
  - Cells with links to: 8 Mile, Avatar, James Bond, Superman, John Wick, Karate Kid
  - `rowspan="3"` cell with `popcorn.webp` image (popcorn)
- Links to individual pages (`8m.html`, `avatar.html`, `agente.html`, `super.html`, `jw.html`, `karate.html`)

### CSS Styles (styles.css)
- Table centered with `margin: 0 auto`
- Collapsed borders (`border-collapse: collapse`)
- Red cells, `200px` height
- Popcorn image with `object-fit: cover` for perfect fit
- Links with colors and `:hover` effects
- Styles for `:link`, `:visited`, and `:hover`

---

## 🛠️ Technologies Used

- ✅ HTML5 (tables, links, `rowspan`)
- ✅ CSS3 (centered tables, `object-fit`, pseudo-classes `:link`, `:visited`, `:hover`)
