📅 Event Manager

Manage your events from the console (F12).

How to use

  • Use the functions in the console to add, list, filter, sort, and delete events.
  • All data is managed in the eventos array.
  • Check the console (F12) to see the results.

Available Functions

  • anadirEvento(nombre, fecha, lugar, precio, estado)
  • listarEventos()
  • filtrarPorEstado(estado)
  • ordenarPorFecha(ascendente)
  • ordenarPorPrecio(ascendente)
  • mostrarDiasRestantes()
  • eliminarEvento(id)
  • resumen()
