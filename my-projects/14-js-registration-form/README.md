# Registration Form

## 📋 Descripción

Programa en JavaScript que solicita al usuario su nombre, edad, país y hobby mediante `prompt()`, y muestra un resumen junto con la fecha y hora actual en un `alert()` y en la consola.

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **JavaScript** (prompt, Date, alert, console.log)

## 📁 Estructura del proyecto

14-js-registration-form/
├── index.html
└── README.md

## 🧮 Funcionamiento

1. El programa pide nombre, edad, país y hobby.
2. Obtiene la fecha y hora actual del dispositivo.
3. Construye un mensaje personalizado con los datos introducidos y la fecha/hora.
4. Muestra el mensaje en una ventana `alert()` y también lo escribe en la consola.

## 📊 Ejemplo de salida (alert)
Gracias Pepe
Has registrado los siguientes datos:
Tienes 45 años, eres de España. Tu Hobby es: Cocinar.
Fecha de Registro:
Madrid 21, Mayo, 2026
Hora: 19:30:38

## 📚 Conceptos aplicados

- ✅ Uso de `prompt()` para entrada de datos
- ✅ Objeto `Date()` y sus métodos (`getDate`, `getMonth`, `getFullYear`, `getHours`, `getMinutes`, `getSeconds`)
- ✅ Array de nombres de meses
- ✅ Concatenación de cadenas con `+` y saltos de línea (`\n`)
- ✅ `alert()` para mostrar mensaje emergente
- ✅ `console.log()` para salida en consola
