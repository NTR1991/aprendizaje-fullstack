📦 Product Catalog

Open the console (F12) to interact with the product manager.

How to use

  • Use the functions in the console to manage products.
  • All data is stored in the productos array.
  • Check the console (F12) to see the results.

Available Functions

  • anadirProducto(nombre, precio, categoria, stock)
  • listarProductos()
  • filtrarPorCategoria(categoria)
  • aplicarDescuento(categoria, porcentaje)
  • ordenarPorPrecio(ascendente)
  • calcularValorTotal()
  • buscarProducto(nombre)
