# 💻 Coding Facts

## 📋 Description

A JavaScript program that shares fun coding facts through the browser console. Demonstrates constants, variables, string concatenation, and variable reassignment.

Create an interactive console-based program that showcases fundamental JavaScript concepts: constants, variables, string manipulation, and console output.

## 💡 How It Works

The program simulates a friendly bot that introduces itself and shares a series of coding-related facts:

1. A `const` is used for fixed values (bot name).
2. A `let` variable is used for dynamic content (coding facts).
3. The `let` variable is reassigned multiple times to demonstrate mutability.
4. String concatenation with `+` combines text and variables.
5. Each message is logged to the console using `console.log()`.

## 🧪 Key Difference: `const` vs `let`

| Feature | `const` | `let` |
| :--- | :--- | :--- |
| Reassignment | ❌ Not allowed | ✅ Allowed |
| Use case | Fixed values (name, location) | Changing values (facts, messages) |
| Scope | Block-scoped | Block-scoped |
