# Coding Facts

## 📋 Description

A JavaScript program that shares fun coding facts through the browser console. Demonstrates constants, variables, string concatenation, and variable reassignment.

## 🛠️ Technologies Used

- **HTML5**
- **JavaScript** (console.log, const, let, string concatenation)

## 📁 Project Structure
13-js-coding-facts/
├── index.html
└── README.md

## 🧮 Concepts Demonstrated

| Concept | Example |
|---------|---------|
| `const` variable | `const botName = "Ernesto";` |
| `let` variable | `let codingFact = "I love " + favoriteLanguage;` |
| Variable reassignment | `codingFact = "I need " + favoriteLanguage;` |
| String concatenation | `"My name is " + botName + " and I live on " + botLocation` |
| `console.log()` | `console.log("Hello!");` |
