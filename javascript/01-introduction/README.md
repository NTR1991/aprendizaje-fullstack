## 🧪 Key Learnings

- `console.log()` – non-blocking console output (F12)
- `alert()` – blocking popup
- `document.write()` – writes directly to HTML (testing only)
- JavaScript is case-sensitive (`console.log` vs `Console.log`)
- Variables declared with `let`
- Comments: `//` (single-line) and `/* */` (multi-line)
