📋 Description
First contact with JavaScript: output methods, case sensitivity, variables, and comments.
📊 Exercises & Results
| Exercise | Code | Console Output / Effect |
|----------|------|--------------------------|
| 1: console.log | `console.log("jacinto"); console.log(22);` | `jacinto`<br>`22` |
| 2: alert + document.write | `alert("Bienvenido");`<br>`document.write("<p>Aprendiendo JavaScript paso a paso</p>");` | Popup message + paragraph added to page |
| 3: let variable and comment | `let curso = "Full Stack";`<br>`console.log(curso);`<br>`// variable stores course name` | `Full Stack` |
🧪 Key Learnings
- `console.log()` non‑blocking console output (F12)
- `alert()` blocking popup
- `document.write()` writes directly to HTML (testing only)
- JavaScript case‑sensitive (`console.log` vs `Console.log`)
- Variables with `let`
- Comments: `//` and `/* */`
