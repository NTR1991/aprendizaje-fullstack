## 📋 Description

This block covers the foundational concepts of JavaScript: introduction to the language, variables, operators, conditional statements, functions, and arrays. All exercises are based on real-world scenarios to build a solid base for web development.

---

## 📚 Topics Covered

| # | Topic | Description | Status |
|---|-------|-------------|--------|
| 01 | Introduction | Basic output: `console.log`, `alert`, `document.write`, comments | ✅ |
| 02 | Variables | `let`, `const`, data types, reassignment, `undefined` | ✅ |
| 03 | Operators | Arithmetic, comparison (`==`, `===`), logical (`&&`, `||`, `!`) | ✅ |
| 04 | Conditional Statements | `if/else`, `else if`, `switch`, ternary operator | ✅ |
| 05 | Functions | Declaration, parameters, `return`, arrow functions | ✅ |
| 06 | Arrays | Basic methods (`push`, `pop`, `unshift`, `shift`) and advanced (`map`, `filter`, `reduce`, `slice`, `splice`, `concat`) | ✅ |

---

## 🎯 Learning Objectives

By the end of this block, you should be able to:

- ✅ Write and run basic JavaScript code in the browser console
- ✅ Declare and manipulate variables using `let` and `const`
- ✅ Use arithmetic, comparison, and logical operators
- ✅ Control program flow with `if/else`, `switch`, and ternary operator
- ✅ Write reusable functions with parameters and `return`
- ✅ Manipulate arrays using modern methods like `map`, `filter`, and `reduce`
